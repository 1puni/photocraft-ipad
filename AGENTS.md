# PhotoCraft iPad

Read README.md and CONTRIBUTING.md. The Rust engine, renderer and shared commands
belong to PhotoCraft; this crate owns the iPad workspace and browser input adapter.
Link and compose instead of copying the editor core. Reusable changes stay as
reviewable upstream patches. Keep independent patches small and preserve authorship.

Lead release copy with what works and how it is built. v0.1 is a version, not an
apology. Keep remaining work in docs/ipad-port.md and measured results in
docs/verification.md. Credit upstream clearly without downplaying this work.

Publication authority is recorded in docs/release-preparation.md. Changes to that
authority require the owner's instruction. Never make the repository public or
deploy a demo just because a local build passes.
